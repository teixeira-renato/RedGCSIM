## Description
This is the first submission of the `RedGCSIM` package to CRAN.

The package implements a reproducible algorithm for redistributing garbage codes from mortality records in Brazil, based on the SIM (Sistema de Informações sobre Mortalidade) dataset, the official mortalitily data system from Ministry of HEalth. It includes functions for standardizing demographic fields, computing proportions for redistribution, and applying rule-based allocation for maternal, external and undetermined causes.

The package has been developed as part of an academic initiative led by GPEAS at UFMG, and is maintained by Renato Teixeira.
